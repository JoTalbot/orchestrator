## Как использовать — по приоритету

### P0. Аудит секретов (сделать первым)
В чатах засвечено **32 секрета**: 26 приватных SSH-ключей (OPENSSH PRIVATE KEY), 5 GitHub PAT (включая действующий `ghp_0LXY…`), 1 AWS-ключ (AKIA…), 1 JWT. Чат-источники: «Подключение по SSH», «Синхронизация инструкций», «Создание SSH навыка», «Безопасность токенов GitHub», «Доработка идеи файловой системы» и др.
→ Всё, что попадало в чаты OpenAI, считать скомпрометированным: перевыпустить SSH-ключи серверов и GitHub PAT, отозвать AWS-ключ. Список чатов с секретами — в metrics JSON.

### P1. История проектов → контекст для агентов-водителей
У каждого проекта уже есть папка и история чатов в ChatGPT, но новый чат в папке начинает с пустого контекста. Чаты содержат дизайн-решения, ошибки и их фиксы («GitHub отклонил blob SHA», «Bridge → replay даёт undefined» и т.п.).
→ Сгенерить per-project дайджесты (решения/архитектура/ошибки/план) и подавать их в INIT-сообщение драйвера. Агент не будет повторять пройденное.

### P1. Бэклог незавершённого
14 чатов повисли на незакрытой задаче: MadWorld MMO (последнее «+»), AIOS/AIOS2 (протоколы, продолжение разработки), «Логотип и дизайн» («сделай глобус овальнее»), генерация видео, «Ссылка восстановления принята» (обновить инструкции во всех проектах) и др.
→ Свести в единый бэклог и докрутить теми же агентами (или добавить в роадмапы репозиториев).

### P2. Готовые спеки и ТЗ
В первых сообщениях чатов лежат полные спецификации: Word Arena (23 791 симв.), Octopus (19 994), механика MMO-арены (12 741), «Нодовая система Бессмертие» (11 975), протокол автономной разработки AIOS2 (10 212), комплект объявлений OLX (8 649).
→ Извлечь в `docs/SPEC.md` соответствующих репозиториев как источник истины.

### P2. Скилы для агентов из реальных решений
Повторяющиеся сценарии: SSH-подключение к серверам, GitHub API-паттерны, деплой на Railway, Kaggle/Colab, работа с data.gov.ua/autosklo, Telegram-боты, CDP/RPA.
→ Сгенерить skill-карточки (по образцу PROFILE.md) и подкладывать драйверу. Частично уже есть (Часть 2), расширить.

### P3. Библиотека сниппетов
31 448 код-блоков — деплой-скрипты, docker-compose, GitHub Actions, парсеры. Извлечь наиболее повторяющиеся в библиотеку `snippets/`.

### P3. RAG-поиск по корпусу (если нужно)
135M симв. — можно поднять векторный индекс (на сервере или в проекте) для семантического поиска «как мы уже решали X». Агентам и Jo — быстрый доступ к прошлому опыту.

## Что уже используется (не дублировать)
- Профиль стиля «Работай как Jo» + системный промт (Часть 2) — `agent_profile/PROFILE.md`.
- Протокол подтверждений «+»/«.»/«да» — в драйвере (`jo_style.decide`).
- Автономные агенты-водители по проектам (Часть 3) — ukraine, game, logistics, fs, transcribe.
